Fault codes (DTC)

        
Requires a live ECU connection (Logger tab must show “connected”). Not available during a Full parameter scan.

        
Diagnostic session: not started — started automatically on the first test (83 03 00 FF 00 FF 00 + 10 81), exactly as GuzziDiag/IAWDiag do at connect.

        

          
          
          
        

        

        
What this does
          
Read fault codes — Reads stored/current diagnostic trouble codes (SAE code + status) via ReadDTCByStatus 18 00 FF 00. Read-only, changes nothing.

          
Clear fault codes — Erases stored DTCs from ECU memory via ClearDiagnosticInformation 14 FF 00. Codes reappear if the fault is still present. Does not touch adaptations, tuning or firmware.

        

      

      

        
Adaptation resets

        
⚠ Engine OFF (kill-switch), ignition ON. Verified for IAW 5AM from the GuzziDiag reverse.

        

          
          

            

            
—

          

          
        

        

        
What this does
          
Reset TPS — Resets the throttle-position adaptation (closed-throttle reference) via StartRoutine 31 21. Do it engine-off / ignition-on; the ECU relearns idle afterwards.

          
Reset self-adaptation — Clears the ECU self-learned fuel/idle adaptation (Selbstadaption) via 30 7E 04. The ECU relearns over the next rides.

        

      

      

        
Actuator tests

        
⚠ Engine OFF (kill-switch), ignition ON. Each button energizes a real output (fuel/spark/pump) for a moment, then auto-off. Confirm each.

        

          
          
          s
          
          
        

        

        

        
Momentary test: sends 30 <id> 07, then 00 when the pulse length runs out. The board owns that timing, so the output is released even if the browser goes away. LocalID→name from JPDiag [Tests]; command byte from the GuzziDiag reverse.

        
* Channel exists in the IAW actuator set but may not be present on this bike — the ECU will most likely answer with an error. Harmless to try.

      

      

        
ECU profiles (reference)

        
Bike → ECU → protocol from the GuzziDiag model table, plus the command set recovered for each ECU family. Reference only — this logger targets the IAW 5AM; nothing here is sent automatically.

IAW status/bitfield meanings from JPDiag. Reference for decoding status channels once their rli is identified.

          System
          
          
          
Off by default. The check compares the calibration in the image with the one the ECU reports and blocks a write only when both are known and belong to different bikes. It cannot tell a good tune from a bad one — it only stops the wrong motorcycle's firmware.

          
          
          
Records USB, Wi-Fi and K-Line events next to the ride logs: what the kernel says about the adapter, when the link came up or died, and a board snapshot every few seconds. On reaching the limit the file is archived to .zip and a new one starts. The files are listed right below; /api/diag.txt opens the current one as plain text.
